A small public Lean exercise, from the binary prefix search in published DOI 10.5281/zenodo.24350515, Lemma 3.2. Return a short standalone Lean 4.35 file importing Std, in namespace PrefixProbe. Implement search (p : Nat → Bool) (fuel lo hi : Nat) : Nat × Nat: zero fuel or hi ≤ lo + 1 returns (lo, 0); otherwise compute mid := lo + (hi-lo)/2, test p mid exactly once, recurse with one less fuel on (mid,hi) for true or (lo,mid) for false, and add one to the returned probe count. Prove search_count_le for all inputs, (search p fuel lo hi).2 ≤ fuel. Use induction on fuel generalizing lo hi, explicit split, and Nat.succ_le_succ or omega. Only implement this function and prove this one elementary count bound. Do not attempt accuracy, midpoint width, or maximality. Output just the Lean file. No sorry, custom axioms or unsafe commands.
