# EX3.1 fresh endpoint fidelity

The generic proof uses the topological comparison of each fresh child
endpoint with both parent endpoints. For arbitrary real parent-child
edges, every tail in a fresh endpoint's exit set remains the same
physical tail in the parent coordinate. The theorem is stated for all
target proper losses and both parent endpoint coordinates.
`finiteSiblingQuotient_edge_exitTailMem_iff` instantiates it on the
actual finite labelled quotient of an original DAG.
