# EX4.1 two-coordinate map fidelity

The two-output map represents each coordinate as an empty-aware join
constant plus zero or one input slot. Identity and closed composition
follow the actual slot selections. The proof retains missing slots.
The preorder extrema representation decodes to the original-tree LCA
under a verified interval contract, including the empty sentinel.

The word encoding carries the exact map and value tags and the bounded
preorder ranks. The roundtrip theorem and field counts apply to the
actual encoded records, and the orientation theorem transports both
input slots and output coordinates together. These records have
constant width. Wiring them into a full built index and accounting the
whole traversal remain under EX4.2 and EX4.3.
