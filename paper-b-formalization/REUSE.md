Mathlib offers nil paths, concatenation and maps on paths in a quiver, which can carry individual arc occurrences. Prefer the existing project reachability definition where its semantics already match. Use the quiver API if it shortens the labelled lifting proof after the toolchain pin. [Mathlib path definitions](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Combinatorics/Quiver/Path.html)

The inspected project sources do not supply a checked end-to-end two-failure oracle. The current new-proof work is the labelled sibling quotient, effective-pair forest, exact exit transfer, compressed maps and the costs of their composition. The executable [Python oracle](../evidence/paper-b-space-20261118/dag_exit_oracle.py) and [direct checks](../evidence/paper-b-space-20261118/check_exit_transfer_review.py) supply concrete regression cases.
