## Proof reconstruction and attempts to break it

- **Lemma 2.1, projection and lifting.** If an arc entered a strict descendant of \(u\) from a tail outside \(D(u)\), a path to the tail avoiding \(u\) would extend to that descendant. Thus a path enters a child block at the child itself. Any chosen original exit tail can be reached internally from that entry. A path could not leave and reenter at the child in a DAG. This proves lifting for the specified arc labels, including parallel quotient arcs. Each retained original arc belongs to the quotient determined by the immediate dominator of its head.
- **Lemma 2.2, partial block failure.** A path to a block root avoiding the other failure cannot visit a strictly lower failure before that root. Join it to the internal suffix avoiding the local failure. In a third properly lost block, distinguish the last visit to either endpoint block. Its original exit tail and its continuation give the two conditions for survival. Conversely such a reachable tail can be extended. For a nonempty tail set, containing its LCA in a failed subtree is equivalent to containing every tail in that subtree.
- **Lemma 3.1, completeness of the forest.** The first proper loss follows both failed endpoints and has precisely those two distinct predecessors. At a later vertex with latest predecessor \(m\), a separator omitting \(m\) is on the ancestor chain of its label. Raw loss, which includes cut endpoints, is the monotone predicate on this chain. A separator containing \(m\) can lose earlier predecessors only at its other endpoint, because the quotient is flat. This yields the sole additional two-predecessor key. For a repeated key, the two predecessor labels and their endpoint memberships are already fixed. New forest nodes only attach as leaves.
- **Lemma 3.2, cost.** Each usable jump clears a set bit of the depth. After an overshoot, the next overshoot has a smaller low bit. Thus a depth lookup costs \(O(L^2)\) moves. Binary search makes \(O(L)\) tests, including the ancestry checks on all distinct predecessors. Charging each distinct predecessor \(O(L^3)\) accounts for repeated edge scans. Sorting distinct predecessors keeps the logarithm bounded by the vertex count even with parallel arcs.
- **Theorem 4.1, both forward inclusions.** A fresh child endpoint \(p\) follows both old endpoints. A route surviving the other child endpoint must visit \(p\), since the child pair loses the target. Its suffix avoids the parent pair, so every tail feeding \(p\) extends. For inherited tails at a shared endpoint \(s\), suppose the continuation visits the other old endpoint \(v\). Flatness supplies a prefix to \(v\) avoiding \(s\), and order excludes the later fresh endpoint from that prefix. Appending the continuation from \(v\) would survive the child pair, a contradiction.
- **Theorem 4.1, reverse inclusion.** If the continuation touches a fresh endpoint, its prefix certifies the fresh contribution there, including a zero-length prefix if the first arc lands on it. Otherwise the continuation avoids the whole child pair. This gives the inherited contribution when \(s\) is shared. When \(s\) is absent from the child, a prefix to \(s\) can avoid the sole possible shared endpoint and all fresh endpoints follow \(s\). Concatenation would reach a properly lost target. The argument works coordinate by coordinate for disjoint pairs and preserves original tail identity before taking any LCA.
- **Lemma 5.1 and Theorem 1.1, the consumer.** Each coordinate is a constant LCA joined with at most one inherited input slot. This representation is closed under composition. When a pair first appears at \(y\), the fresh endpoints \(p\) precede \(y\). All forest edges needed to lift from \(c(p)\) already appeared no later than \(p\), so installation before computing \(y\)'s base is well founded. An arc or pair installation needs only a constant number of traversals. There are \(O(L^2)\) moves per traversal and each physical-tree LCA costs \(O(L)\). Summing all quotients charges \(O((n+m)L^3)\) construction time and \(O(n+m)\) working words. Discarding arcs leaves \(O(n)\) words usable for every subsequent \(O(L^3)\) query. Corollary 1.2 charges all lists, their \(M\) target occurrences and the output vector.

## Checks that discriminate between correct and incorrect variants

The [new independent checker](check_physical_tails.py) finds the forest edges using direct deletion and containment of proper-loss sets. It expands skeletons into actual graphs with distinct physical tail vertices, multiple tails for a quotient adjacency, a tail reused across heads and repeated arcs. The LCA test is compared to search in the expanded graph. It imports no manuscript algorithm. Of 3,374 ordered flat skeletons through six vertices, 212 have nested cuts. Two physical realizations of each gave 976 exact tail-set comparisons and 4,392 failure-pair/target comparisons. All matched. Dropping either side lost information in 256 individual coordinates that needed both contributions. Replacing every physical tail by its block root gave 126 wrong Boolean answers. These counts cover the specified test families. [Results](physical-checks.json)
